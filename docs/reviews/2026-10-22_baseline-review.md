## 三、MECE 逐项
- **业务闭环**:立项(类型/方案/结构/时长/估算)→ 故事 → 媒体 → 成片 → 交付,入口明确;旧项目(空方案)按全局配置运行,已在生产库副本验证。
- **架构边界**:方案经 `Settings.for_pipeline` / `Ledger.settings_for` 统一取值,没有各处复制;模型过期判定与生产计划、系列看板、流程计数共用 `up_to_date`;换方案的方向规则(有图后不能跨竖/横)有测试。
- **权限与审计**:见 P2/P3;合规开关(全局/环境/项目)与溯源分离,溯源始终记录。
- **数据幂等**:作业幂等键、租约、重投未变;迁移 013 向前兼容;新增 ComfyUI 上传用"作业 id + 序号"命名,重投覆盖同名文件,不会堆积。
- **仪表盘与钻取**:看板/计划/流程计数一致性有对账测试(本次又修了"旧素材判过期"导致的分歧并有测试)。
- **可用性**:新建项目是向导,类型/方案带出默认并显示估算;方案可改但受方向规则约束。
- **i18n**:新增文案全走键,`react/jsx-no-literals` 与 `test_guards` 通过;语言包一致。
- **可观察性/回滚**:迁移前自动快照(`.bak-v12` 已在);回滚 = 恢复快照 + 回到旧提交;`media healthcheck` 现按方案体检。
- **发布准备**:见 P1;web 产物为本地构建。
