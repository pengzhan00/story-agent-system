### 2. 能否覆盖媒体创作场景?——**生产链覆盖,创作工作流不足,已补**

媒体创作的真实循环是「**试看 → 挑选 → 改词重来 → 锁定 → 精修 → 出片**」,不是一次性流水线。原计划缺:
- **质量分档**:旧系统有 smoke/preview/production,原计划丢了。AIGC 是"抽卡",必须便宜地多试。→ 新增 `QualityTier`(draft / preview / final)并贯穿 `MediaJob`。
- **候选与挑选**:同一镜头多 seed 候选、并排对比、采用/锁定 seed、只重做单镜头。→ 台账 `media_assets` 的版本 + `current` 指针已能承载,R3/R4 增加候选工作流与 UI。
- **审核闭环**:旧系统有 approve/reject/rework/lock 状态机,原计划 R4 未提 → 见对照表 B2。
- **专业后期出口**:创作者常在剪映/Final Cut/达芬奇精修。→ 交付包输出分轨(画/配音/BGM/SFX)+ SRT + EDL/FCPXML(R5)。
- **系列化生产**:项目默认 80 集,需要「系列圣经」(角色/场景/风格锁定)与跨集一致性。
- **内容语言 ≠ 界面语言**:已加 `projects.content_language`。

### 3. 人因工程 / 易用性是否满足?——**原计划不满足**(R4 只有一行)

要求已写入计划(见计划文件 v2.1「R4 人因与易用性验收」),要点:
1. **用户与任务**:先定义两类用户——"一键出片的新手"与"逐镜头精修的创作者";首页「快速成片」(单提示词→draft→final)与「完整管线」分层,渐进披露,默认值安全。
2. **长任务反馈**:视频任务以分钟~小时计 → 必须有进度、基于成本账本的 ETA、队列可见、可取消、完成通知(macOS 通知)、休眠提醒;关闭页面不丢任务(worker 持久化已满足)。
3. **可恢复错误**:每个错误码配 `error.<code>.remediation`("发生了什么/为什么/下一步做什么")的 i18n key,而不是堆栈。
4. **可逆与可追溯**:任何覆盖都有版本、可回退;删除走回收站;破坏性操作二次确认并写审计。
5. **数据一致**:看板计数必须与钻取列表一致(加自动化对账测试)。
6. **可验收的易用性指标**:例如"首次从空项目到 draft 成片 ≤ N 次操作"、"任一失败镜头 ≤ 2 次点击重试";用任务式走查 + Nielsen 十原则清单作为 R4 验收。
7. **一致术语**:建立术语表(镜头/场/幕/集/作业/资产),UI、日志、文档统一。
8. **无障碍**:键盘可达、对比度、不只靠颜色表达状态(状态用图标+文字+i18n 标签)。

### 4. MECE 是否满足?——**部分不满足,已修**

- ✅ 阶段划分(分析→剧本→选角→场景→美术/音乐/音效→分镜→媒体→装配→导出)互斥且穷尽。
- ❌ **原 `MediaKind` 不 MECE**:`video_audio` 与 `video`/`music`/`tts` 交叠,`assemble` 是装配而非生成,缺 enhance/edit/asr/lipsync/qc。→ 已改为 `<输出域>.<操作>` 的 14 类(`image.generate … analyze.qc`),子模式放 `params['mode']`。(代码:`storyagent/domain/enums.py`,含 i18n 标签与测试)
- ❌ **模型与运行时混为一谈**:H3 与 FastVideo 是同一模型族的两个运行时,许可按模型族而非运行时。→ `models.toml` 新增 `family`;`provider` 明确为运行时。
- ❌ **需求 MECE 缺口**:重写缺"旧功能去向表"。→ 新增 `docs/PARITY_MATRIX.md`,R7 删除旧代码以其全绿为门禁。
