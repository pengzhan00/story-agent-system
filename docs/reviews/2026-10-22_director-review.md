# 导演视角审查:系统性与完整性(MECE)—— 2026-10-22

范围:`storyagent/` 当前基线(HEAD ce82666)。方法:按影视制作的工序逐项对照代码、配置、提示词和试播实测;"未见"= 在代码/配置/提示词里查不到,不等于一定没有。
不是发布审查(那个见 `2026-10-21_series-layer.md`),这里只问一件事:**一个导演要把一个想法拍成片,这套系统有没有覆盖全部工序,工序之间接得上吗?**

## 一、划分维度(互斥、穷尽)

按"片子从无到有经过哪些工种"切,每一块只归一处:

| # | 工序 | 导演要回答的问题 |
|---|---|---|
| 1 | 开发/立项 | 拍什么、给谁看、多长、多大规模、花多少 |
| 2 | 编剧 | 故事成不成立、结构对不对、每集每场干什么 |
| 3 | 视觉:摄影与调度 | 镜头怎么设、怎么切、人在画面里怎么动 |
| 4 | 视觉:美术/服化道/灯光/色彩 | 世界长什么样、前后是否一致 |
| 5 | 表演与选角 | 谁演、怎么演、声音像不像 |
| 6 | 声音 | 对白、环境、音效、音乐、混音 |
| 7 | 剪辑与后期 | 节奏、转场、调色、字幕、包装 |
| 8 | 制片管理 | 进度、预算、审片、改稿回路 |
| 9 | 发行交付 | 成什么规格、合规、多版本 |

## 二、逐项结论

图例:✅ 有且已实测 / 🟡 有但薄或没接通 / ❌ 没有

### 1 开发/立项 —— ❌(最大的结构缺口)
- 有:创意 → `director.analyze` 出名称、类型、基调、摘要、角色、地点、风格关键词。
- 没有:**作品类型**(短剧/广告/电影/电视剧)、**受众与平台**、**一句话主题(logline)与主题陈述**、**分季分集和时长计划**、**规模与算力估算**、**参考片/情绪板**(参考图只在人物/场景层,立项层没有)。
- 后果:同一句话,广告和电影写出来一个样;集数和时长要到后面才补。已在 `docs/BRIEF_AND_INTERCHANGE.md` 记录方案。

### 2 编剧 —— 🟡
- 有:分季(`screenwriter.season`)、分集大纲、按集写剧本、剧本审查(`reviewer.script`,出评分和问题)、改编(`screenwriter.adapt`)、每集钩子和结尾悬念进提示词。
- 缺:
  - **结构检查是写在提示词里的"愿望",没有代码核对**:钩子在前几秒、每幕有反转,没人量。
  - **改稿回路**:审查给出问题后,没有"按批注改"的一键重写与前后对比(未见 revision/feedback)。
  - **人物弧线、伏笔回收**没有账本:跨集的"埋了什么、谁来收"没有数据结构,只靠"前几集梗概"喂给模型。
  - **主题**只在配乐里出现,剧本层没有主题字段。

### 3 视觉:摄影与调度 —— 🟡(导演最该盯的一块)
- 有:镜头记录 `shot_type`(景别)、`camera_movement`、`camera_notes`(文字);每场固定 N 个镜头;视频/静图分层;关键帧由人物像+场景图合成。
- 缺(**这些是"看着像片子还是像 PPT"的分界**):
  - **镜头语法**没有:场景建立镜头 → 全景/中景 → 特写 → 反应镜头的覆盖规则、景别跳切规则,没有代码校验(现在由 LLM 每场随手出 N 个)。
  - **轴线/视线/屏幕方向**未见(180° 原则、人物谁在左谁在右、出画入画方向)。对话场景正反打会"穿帮"。
  - **镜头焦距/景深/机位高度**只是文字里偶尔带到,不是结构化字段,进不了提示词模板。
  - **镜头内的动作调度(blocking)**没有:一个 5 秒镜头里人物从哪到哪、起止姿态,只有一句 `action`。试播"走路飘、横纹"一部分就是这个原因:模型拿到的是"走路",不是步态、落点和机位。
  - **单镜时长**由台词量和规划值决定,没有"这个镜头该多长才有节奏"的依据。

### 4 视觉:美术/服化道/灯光/色彩 —— 🟡
- 有:风格指南(调色板、光、氛围、`visual_style` 进每条提示词)、场景设计(光、色、氛围、陈设)、人物外貌和"稳定描述"、人物锁定。
- 缺:
  - **服装是空的**:`shotplan.py` 里每个角色的 `costume` 写死为空串,**没有按集/按场的造型表**(同一人物第 3 场换了衣服、第二季换装,系统不知道)。
  - **道具**没有实体:剧情里的关键道具(试播里的"纸条")没有统一外观与出现记录,每个镜头各画各的。
  - **连续性**(时间、天气、伤痕、衣着脏污)只在场景层有 `time_of_day/weather`,没有"上一镜是什么状态"的传递。
  - **场景/画风锁定**(S1 里没做的那半):人物能锁,场景和风格不能。
  - **成片调色**未见(compose 没有统一调色/LUT/镜头间色彩匹配一步)。

### 5 表演与选角 —— 🟡
- 有:人物档案(性格/背景/关系)、声线描述、参考音频与授权、CosyVoice 克隆、口型头像(lipsync 模型已登记,默认流程未接)。
- 缺:**表演指导**——每句台词的情绪、语速、停顿没有字段进入合成(台词只有文本和声线);人物"表情/微动作"只在 `action` 一句话;口型对白镜头默认不走口型。

### 6 声音 —— 🟡(这块已比其他部分完整)
- 有:对白(先量时长再排时间轴)、配乐(按集)、主题曲、每镜音效(`shot.sfx`,Stable Audio)、闪避、响度归一、音效按镜头起止裁切。
- 缺:
  - **环境底噪(room tone / 场景氛围)** 作为持续一层没有;现在只有点状音效,场景静默会"穿"。
  - **一集多段配乐、配乐的出入点(spotting)**没有(S5 记为没做)。
  - **混音按场景分层**没有:对白/环境/音效/配乐各自的电平曲线是全局常数。

### 7 剪辑与后期 —— 🟡
- 有:以台词时长定镜头长度的 EDL、场景淡入淡出、片头/片尾/回顾卡、字幕样式、AIGC 标识叠加、质检。
- 缺:
  - **剪辑语法**:音画错位剪辑(J/L cut,声音先于或晚于画面)、叠化、匹配剪辑都没有(叠化因"需重叠音画"没做)。
  - **节奏分析**:没有镜头长度分布、对白密度的检查与建议。
  - **调色/降噪/去条纹**后期没有。
  - **外部剪辑往返**没有(已记录方案)。

### 8 制片管理 —— 🟡
- 有:线性队列、内存护栏、进度+剩余时间、生产计划(先看清单再确认)、规格版本与回退、候选采用、系列看板、台账溯源。
- 缺:
  - **审片(dailies)回路**:看完一个镜头 → 写"哪里不对" → 系统改提示词/参数重做,这条线没通(规格能手改,但没有"批注 → 重写 → 对比")。
  - **预算和排期**在立项里没有(只有事后的视频预算)。
  - **版本对照**:剧本、规格有 diff,成片两版之间没有。
  - 横纹这类"质量问题"没有**自动质检项**(条纹、闪烁、人物突变),现在 QC 只量文件/时长/黑帧/冻结/响度。

### 9 发行交付 —— 🟡
- 有:交付档位、AIGC 标识与元数据、交付包(成片/SRT/分轨/来源/清单)、质检。
- 缺:**多平台规格**(网络 -16 LUFS 与电视广播 -23 LUFS 是两套)、**封面/海报/预告片**、**横竖屏复用(重构图)**、多语字幕。

## 三、MECE 自检:系统本身有没有"重叠/漏洞"

**重叠(同一件事多处管)**
1. 模型选择在三处:`[defaults]`、项目 `settings.models`、工坊预设;`recipes.toml` 只读不执行。→ 管线方案要合并(已记录)。
2. 镜头信息存两份:`shots` 表列(`shot_type/camera_notes/visual_prompt`)和 `render_payload` JSON,互相不是权威。
3. 时长有 4 个来源:档位范围、`target_sec`、规划时长、台词实测,优先级靠约定,没有一张图写清。

**漏洞(工序间接不上)**
1. 立项 → 编剧:集数/时长/类型进不来(缺口 1)。
2. 编剧 → 镜头:剧本里的"伏笔、道具、服装"到镜头层丢失(缺口 4)。
3. 镜头 → 成片:镜头语法与轴线不检查,到了剪辑才发现"接不上"。
4. 成片 → 返工:看出问题后没有"批注驱动的重做"。

## 四、优先级建议(以"导演最痛"排序)

| 级别 | 事项 | 理由 |
|---|---|---|
| P0 | 立项向导(类型/季集/时长/估算)+ 管线方案 | 目标不完整,后面所有阶段都靠猜 |
| P0 | 视频参数调优(横纹/飘) | 试播实测的硬伤;先做单因素对比再改默认 |
| P1 | **造型/道具/连续性账本**(服装表、道具实体、上一镜状态) | 一致性是"像一部片"的底线;现在服装为空 |
| P1 | **镜头语法层**(覆盖规则、景别跳切、轴线与屏幕方向、镜内调度字段) | 把 LLM 随手出镜头改成有规则的分镜 |
| P1 | 审片回路(批注 → 改写 → 对比) | 迭代的主通道 |
| P2 | 环境底噪/多段配乐/场景混音 | 声音补齐 |
| P2 | 剪辑语法(J/L cut、叠化)+ 外部剪辑往返 + 成片调色 | 观感提升与专业工具衔接 |
| P2 | 自动质检扩展(条纹/闪烁/人物突变) | 把"人看出来的毛病"变成可测 |
| P3 | 多平台规格、封面/预告、横竖屏复用、多语字幕 | 交付完整性 |

## 五、结论

- **工序覆盖**:9 块里,没有一块是完全空白,但**只有声音和交付接近完整**;立项是空的,视觉(摄影/美术)是最薄的。
- **MECE**:按工序切是互斥且穷尽的;系统内部有 3 处重叠、4 处工序接口漏洞,主要集中在"开发 → 编剧 → 镜头"这条线上。
- **一句话**:系统把"生成素材 → 拼成片"这条**制作线**做通了,但**导演线**(立项、镜头语言、造型连续、审片返工)还没成体系——现在是"能出片",还不是"能按导演意图出片"。
