## 2. MECE 覆盖检查

| 领域 | 设计覆盖 | 实施验收 |
|---|---|---|
| 业务入口与主流程 | 工坊/项目/批量使用同一计划；创建、审核、采用、装配、发布、回收 | G01/G05/G09/G11/G12 |
| 能力空间 | t/i/a/v 转换方向与具体操作分离、多输入多输出、训练模型资产 | W0/W2、G05/G07/G08 |
| 领域对象与状态 | 定义/版本/实例/尝试/结果/采用/修订各有边界 | §13，G02/G03/G09/G11 |
| 编排与运行 | DAG、分支汇合、动态展开、资源、取消、重试、人工等待、恢复 | G02–G04/G06 |
| 资产与数据 | 文件/表示/血缘/缓存/采用/回收，旧数据回填、缺文件明确处理 | G06/G09/G13 |
| 权限与审计 | 沿用角色和分级，真实对象检查、缓存隔离、平台记录及连接器权限 | G10/G11 |
| 发布归类 | 目的地/内容分类/状态分维，一对多、多对一及历史修订 | G11/G12 |
| UX/i18n/API | 可发现入口、预演阻塞、双语状态、类型生成、无占位成功 | G01/G12/G14 |
| 可观察性与估算 | trace、外部任务、等待原因、实测属性、参数/硬件证据与计数钻取 | W1/W4/W5 |
| 迁移/回滚/运维 | 副本迁移、旧路径开关、备份恢复、未知外部提交不盲重发 | G03/G04/G13 |

“MECE”针对职责和事实源不重复、主要生命周期无遗漏，不意味着每个模态组合都存在可用模型。矩阵中的待验项不得被视为实现已完成。
