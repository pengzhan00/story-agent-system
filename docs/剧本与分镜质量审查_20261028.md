# 《今年夏天》剧本与分镜质量审查（project 7）

审查对象：storyagent `data/storyagent.db`
- `scripts` id=12《今年夏天》12 场 / 3 幕 / 37 镜 / 15,079 字
- `shots` 32 条（前一次重新生成的产品）
- `scenes` 9 条（公寓、办公室、沿海公路、车内、海滩、沙滩、沙丘、浅滩、海边）
- `characters` 3 条（陈远 男主 / 林汐 女主 / 王经理 反派·压力源）
- `gen_specs` 238 条（video.generate 56 / image.generate 68 / audio.sfx 87 / audio.tts 26）

审查方式：逐场读 acts JSON 原文 + 对 shots 表逐条比对 + 与 characters/scenes 交叉核对。以下每条都指向具体字段与原文。

---

## 一、故事层面的硬伤（不定就改不动片子）

### 1. 反派在剧本里完全缺席
`characters` 里有「王经理 / 反派·压力源」，外貌设定写得很细（眉心常年锁紧、目光审视、侧分短发带白发）。
但在 37 镜剧本里他**一次都没出现**，`shots` 32 条的 `characters` 字段里也是 0 次。

场1 的 beat 只写「陈远在生日当天被通知优化」——**谁通知的？没有这个人**。
于是「被优化」这件引发全片的事，变成了一个没有施动者的状态描述。观众看不到压力源，就看不到他要逃离什么，"放下焦虑"也就无处落地。

### 2. 匿名磁带的来源永远没有交代
场2：`beat` = 「收到一个没有寄件人的包裹，里面是一盒名为《今年夏天》的旧磁带」，台词「谁寄的？」提出疑问后，全片再无回应。

这是全片最大的悬置。观众会把它当成漏洞而不是悬念——因为它既不指向人物，也不指向后文。必须给一个可推的线索（磁带盒内侧的字迹、快递单上的地名、或她的一句"我还以为你收不到"）。

### 3. 林汐为什么恰好在海边，没有交代
场4：`action` = 「镜头从陈远的侧脸平移，林汐身着黑色吊带长裙，静静地出现在他的身侧」，台词「你迟到了。」

一个 48 岁男人凌晨驱车七小时后，一个穿黑吊带裙的女人"刚好"站在他要去的海边等他——剧本没有给任何解释。她是常住这里？一直在等？还是记忆/幻影？三种解释对应完全不同的片子，现在哪个都不是。

### 4. 时间线与动机自相矛盾
- 场3 `beat`：「陈远**没有请假**，在凌晨驱车七小时前往二十年前那个海边地名」——他在场1 已经被优化，不存在请假。
- 场3 第 2 镜台词「终于到了」，但此时车还在公路上（第 3 镜才是"车辆缓缓停在海边路标前"）。台词位置错了一镜。
- 场2 是夜，场3 是凌晨，场4 是清晨——可以成立；但场2-2 标「正午·烈日」，与相邻场次的夜/凌晨冲突。

### 5. 对白密度与 MV 形态冲突
37 镜里几乎每镜都有台词，且多为书面语： 「你现在，就很真实」「这次打算待多久？」「没什么，只是觉得，这样的人生太无趣了」。

这是一支**歌曲占满 4 分 02 秒**的 MV。台词既不能真配音（会与唱段打架），也不能全靠口型（a2v 只做到嘴在动）。实际可用形态只有三种：字幕、无声表演、或删掉。现在这个对白量决定了它只能当剧情片拍，与音乐形态打架。

## 二、分镜（shots 表）的技术性错误

### 6. `shot_number` 全库不唯一
32 行里出现 3 组 `1,2,3,1,2,3…`（每幕从 1 重新编号）。无法唯一定位一个镜头，任何按 shot_number 排序/引用都会错乱。

### 7. `narration` 字段被视觉提示词占用
32 条 shot 的 `narration` 全是「wide shot, a dark office at night, half the lights off…」这类视觉描述；真正的旁白（「生活在这一刻被强制清零。」「时隔多年，海风依旧。」）只存在于 `scripts.acts` 里。
→ 叙事文本在重新生成时被覆盖丢失，这也是成片"看不懂剧情"的直接原因之一：**渲染链路读到的是画面描述，不是旁白**。

### 8. 唱歌镜头 18 条 = 75% 时长
32 镜中 18 条 `visual_prompt` 为 "he sings" 的近景/特写，同一个人同一张脸占满 75% 时长。真正的戏——被通知、拆包裹、说出恐惧、留下工牌——被压进 3–4 秒的 B-roll。

### 9. 关键戏剧节点在 shots 里消失
场4-2 是两人相遇（她"出现在身侧"+"你迟到了"），`shots` 里对应位置却是 "she sits watching the waves"。
→ **相遇这个全片最重要的节点没有了**，两个人直接进入"并肩散步"。

### 10. 景别失衡
32 镜里 wide 仅 4 条，其余 close/medium。缺建立镜头，观众不知道空间关系，也无法判断他从哪来到哪去。

### 11. 场景名同义混用
9 个场景里，海滩 / 沙滩 / 沙丘 / 浅滩 / 海边 是 5 个高度重合的海边变体，视觉上无法区分。同时「公寓」有完整场景设定却只用于拆磁带两镜。

### 12. 分镜不带时长
所有 32 条 shot 无 `duration_sec`（剧本 acts 里每条都有）。渲染时只能平均分配 → 与歌曲段落对不上，这也解释了上一版"整片节奏散"。

## 三、修改方案

### A. 必须由你定夺的两个创作前提（我不替你编）
1. **磁带是谁寄的？** 三个方向：她自己寄的（她一直在等）／他自己二十年前寄出、被退回／旁人（王经理/同事）转交。
2. **林汐是谁？** 活着的旧友（一直住在这里）／已故的人（MV 允许）／他的记忆投射（海里没有第二个人）。

这两条定了，场2 的线索镜头和场4 的相认方式才能写实。

### B. 我可以直接改的（机械/结构层，不动你的文风）
1. **给王经理加戏 3 镜**（用已有角色设定）：会议室当面通知优化（中景，文件推过桌面）／走廊玻璃隔断后看他抱纸箱离开（wide）／夜车里一条"交接还没办完"的消息（近景手机）。
2. **`shot_number` 全库唯一化**：`act*100 + 场内序号`，同步修正引用。
3. **`narration` 与 `visual_prompt` 分家**：旁白从 `scripts.acts` 回填（≤15 字/条），视觉描述只留 `visual_prompt`。
4. **唱歌镜头 18 → 10**，构图打散（近景 3 / 中景 3 / 过肩 2 / 远景人影 2）。
5. **按歌曲段落补 `duration_sec` + `section`**：intro 12.3 / verse 24.0×3 / chorus 24.0×4 / 长 verse 48.0 / outro 13.2，合计 241.7 秒。
6. **场景 9 → 5**：办公室、公寓、车内（含沿海公路）、海滩（含沙丘）、浅滩。
7. **补每条 shot 的渲染字段**：`mode`（a2v/i2v）、`still`（关键帧）、`ref_character`、`seed`，让适配器能直接派发并回写 `media_assets`。

## 四、审查结论

剧本的**文字能力没问题**（场景氛围、光位、情绪标注都很扎实，沙丘"每年夏天都会变"这类细节是好的），问题集中在三处：

1. **反派出场 = 0**，压力源没有肉身 → 冲突不成立
2. **两个关键悬置（磁带来源、她为何在场）不落地** → 情感不成立
3. **分镜层把叙事文本覆盖成了画面描述，并把 75% 时长给了近景唱歌** → 剧情不可读

前两条要你拍板，第三条我可以直接改。
