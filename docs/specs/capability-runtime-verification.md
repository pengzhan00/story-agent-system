# 能力与运行时契约的验收约束

2026-10-30；源自真实媒体测试。当前修复已在工作树，后续治理任务为 P1，排在完整资源绑定治理界面之前。此文件不是已派发给外部代理的任务。

## 当前已修复的系统性模式

1. 症状：模型已配置但统一编排提示 Unknown capability（audio.sfx）。根因：只枚举工坊历史模块，没有反向校验配置模型。约束：除独立 export 动作 compose.deliver，所有内置创作模型都必须存在输入/输出契约。禁止把服务在线当作功能入口已经接通。自动守卫：`test_packaged_creative_models_all_have_workshop_input_contracts`，以及音效真实 API 预演/派发回归。
2. 症状：参考图/源音频请求在真实服务返回 422/400。根因：Draw Things 要求 init_images 尺寸与请求一致，ACE-Step 不接受客户端绝对路径。约束：传输层在最终有效参数合并后适配媒体，源/参考音频分别上传；不得关闭服务路径保护。自动守卫：Draw Things 的图片/视频两类 HTTP 尺寸断言，ACE-Step multipart 双文件与无绝对路径断言。
3. 症状：Demucs 目录存在但无法加载 955717e8。根因：旧目录只有不匹配当前 PyTorch runtime 的 safetensors；operator 的 .extra 嵌套目录未被 adapter 消费。约束：明确的本地仓库在派发前检查 .th；同时识别已有平铺和嵌套 metadata，顶层值优先。禁止下载一份重复权重掩盖本地目录错误。自动守卫：本地格式错误在真实 worker 边界返回 missing_model；本地目录参数进入命令；额外真实歌曲分离与缓存复用证据。

## 后续 P1：可重复的验收清单

- 建立按 capability/binding/version 的实测清单，区分 configured、在线、权重/依赖齐全、真实任务完成、人工质量接受。每条证据记录源版本、输入哈希、参数、外部任务 ID、资产与媒体探测结果。
- 每新增转换模式至少覆盖一次实际传输边界：类型/必需字段、文件上传、最终尺寸/帧数/时基、具名输出、缺资源错误。不能仅测试 Python body builder。
- 小样统一用独立数据家目录和已有 worker；保留内存门禁，不占用生产数据库；服务/任务超时不能被“返回空数组”吞掉。
- 记录峰值内存与缓存驻留，后续建立分辨率/时长/质量的 profile；当前固定 64 GiB 估计仍保守，不能为了验收成功直接关闭内存保护。
- 验收矩阵覆盖工坊输入 → 图预演/派发 → 实际产物 → 项目采用 → 发布登记；发布登记可在隔离库操作，不发送真实平台帖子。
- 回归以行为与输出媒体为证据，不接受源码字符串搜索代替验证。冻结新范围后再执行完整 software-system-review。

## 2026-10-30 补充：容器时长不是音画对齐证据

真实多片小样曾显示容器3.5秒，但视频流3.375秒、音轨3.5秒。根因是8n+1帧数向下取整，短尾段欠3帧；容器取长音轨掩盖了欠帧。约束：渲染帧数向上覆盖请求区间，overlap 包含在单片可靠窗口内；拼接后分别检查 video/audio stream duration，不能只读 format.duration。禁止静默变速或自动冻帧掩盖未声明的缺片；仅显式 freeze_last 策略允许有界冻结。守卫：`tests/test_lipsync.py` 短尾/窗口边界、真实 ffmpeg 的短视频长音轨负例与最终逐流时长检查。
