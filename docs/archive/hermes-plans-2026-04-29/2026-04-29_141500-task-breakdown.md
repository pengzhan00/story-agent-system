# 红果短剧 Phase 1 — 实施任务

## 两个并行工作流：

### Task A：Writer prompt + shot 生成逻辑
**目标**: 让一集产出 5幕×4场景×3shot = 60 shot（不是现在的 3幕×3场景×1shot = 9 shot）

**修改文件**:
1. `agents/writer/core.py:generate_storyline()` — acts默认=5, scenes_per_act=4, shots_per_scene=3
2. `agents/writer/core.py` — prompt模板改为短剧风格（红果特色：快节奏、强反转、密集台词）
3. `core/orchestrator.py:_create_shot_plan_txn()` — shot_number递增，按scene.shots列表创建多个shot
4. `core/orchestrator.py` — 多集循环（episode_number循环），每集调用writer独立生成

### Task B：Render管线正确使用 + TTS/BGM集成
**目标**: 渲染走RenderDispatcher选管线、prompt从shot注入、TTS+BGM接上

**修改文件**:
1. `core/orchestrator.py` — render阶段改为RenderDispatcher.render()而非BatchRenderer
2. `pipelines/render_pipeline.py` — 添加动态prompt注入方法（替换workflow JSON中的占位符）
3. `core/orchestrator.py` — 添加TTS阶段（ChatTTS批量调用）
4. `core/orchestrator.py` — 添加BGM阶段（MusicGen）
5. `core/orchestrator.py` — 添加合成阶段（ffmpeg视频+TTS+BGM→最终MP4）
