## 三之二、镜头呈现方式（视频 vs 静图）

- **当前数据**：48 个镜头，全部 `treatment = auto`；已生成动态视频 **14** 个、关键帧 48 个。
- **设置层级**：
  - 项目 `settings.video_share`（0–1）：「工作流」页「视频占比」。已设为 **1.0**，即 48 个镜头全出视频。
  - 单镜头 `treatment`（auto / video / still）：「故事」页「呈现方式」。`video` 强制出视频，`still` 永不出视频（优先于 share）。
  - `video_min_per_episode`（默认 2）、`video_budget_hours`（0=不限）：一般不用动。
- **选择算法**：`storyagent/workflow/tiering.py` 的 `video_shots()` —— 先算 `want = max(min_per_episode, ceil(share × 镜头数))`，再按「开场钩子 / 集尾悬念 / 幕头 / 场头 / 有运镜」打分排序取前 `want` 个，`treatment=video` 的强制加入、`still` 的排除。

## 三之三、项目级 AI 提示词（本次新增）

- 存储：`projects.settings['agents'] = { "<agent 名>": {"system"?, "prompt"?, "temperature"?, "max_tokens"?} }`。
- 合并：`storyagent/agents/registry.py::with_overrides()`，引擎 `WorkflowEngine.agents_for(project)` 在 `run_stage` 里按项目叠加；**没有配 `agents` 的项目完全不受影响**（仍用共享/打包提示词）。
- 网页：「提示词」页顶部新增**项目下拉 + 「只改这个项目」开关**；打开时保存写入该项目 settings，关闭时写共享覆盖（`$STORY_AGENT_HOME/config/agents/`）。
- 热读：agent prompt 每次调用重新读盘（`AgentRunner.specs`），改完下一轮即生效，不用重启。
- 适用：`screenwriter.outline` / `screenwriter.adapt` / `screenwriter.shots` / `shot.visual` 等所有 agent。
