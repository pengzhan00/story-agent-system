# 使用指南

## 第一次做一部短剧

1. **启动**:`scripts/start.sh`,浏览器打开它打印的地址。右上角可切换中文 / English;「系统」页显示本机哪些模型和服务可用(绿色=可用,其余会告诉你缺什么)。
2. **新建项目**:写项目名和一两句故事前提(谁、发生什么、在哪)。
3. **开始制作**:「制作流程」页点「开始制作」。会依次完成策划、角色、剧本、场景、配乐、分镜、规格。每一步都有进度条、完成数量、当前在做什么和预计剩余时间;关掉网页不影响,回来接着看。
4. **修改**:「故事」页可改角色、场景、配乐/歌词、分镜和对白;改完会自动同步到生成规格,不需要重做整个流程。「创作」页改每个产物的提示词、参数、种子,可一次生成多个候选并排挑选,选定后「用这个」。锁定的分镜/规格不会被重新规划覆盖。
5. **给角色配声音**:「故事 → 角色 → 编辑」里上传 3–20 秒的清晰录音,写下录音里说的话,并确认说话人同意被克隆。没有声音样本的角色,台词只显示字幕(除非配置了默认声线)。
6. **生成素材**:「生成素材」会把每个规格变成图片、配音、音乐和视频(先出草稿质量)。进度同样可见;失败的单项可在「任务」页重试,其余保留。
7. **合成成片**:「合成成片」得到成片和字幕,下方是质量检查结果和「需要留意」的清单(例如某镜头只有静态图,已用缓慢推近代替)。
8. **交付**:「下载」取成片,「下载交付包」取成片 + 字幕 + 分轨 + 清单 + 溯源。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 「开始制作」一直排队 | 没有 worker:用 `scripts/start.sh` 启动,或另开终端 `storyagent worker` |
| 提示语言模型无法连接 | 启动 Ollama(或你在 `llm.toml` 配的服务),然后再点一次,已完成的内容会保留 |
| 生成素材后提示「已跳过 N 项」 | 点开原因:没有可用模型(去「系统」页看缺什么)、角色没有声音样本等 |
| 想要更高质量 | 素材默认是草稿档;在命令行 `--param tier=final`,或在「创作」页对单个规格重新生成 |
| 不想要 AIGC 标识 | 全局 `compliance.toml`、环境变量 `STORY_AGENT_COMPLIANCE=off`,或用接口 `PATCH /api/projects/{id}/settings` 对单个项目关闭(责任自负) |
| 删错了项目 | 项目页「移入回收站」可恢复:项目列表右上「回收站」→「恢复」 |

更多排障见 [RUNBOOK.md](RUNBOOK.md)。
