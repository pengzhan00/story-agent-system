# 知识库(Wiki)

系统内嵌的知识库:把仓库自己的文档和你 Obsidian 里的笔记放进同一个可搜索、可互相跳转的页面(网页 **知识库**,命令行 `storyagent wiki ...`)。
笔记留在原处,系统只读取、从不修改;页面是复制进数据库的一份(`wiki_pages`),随时可以重新同步。

## 来源

| 来源 | 内容 | 开关 |
|---|---|---|
| `docs` | 仓库的 `docs/**/*.md` | `[wiki] docs = true`(默认) |
| 自己的笔记文件夹 | 例如 Obsidian vault | `$STORY_AGENT_HOME/config/wiki.toml` 的 `[[wiki.sources]]` |

```toml
[wiki]
docs = true

[[wiki.sources]]
name = "obsidian"                       # 页面来源名,不能含 "/",不能叫 docs
path = "~/Documents/Obsidian Vault"
include = [                             # 允许读取的清单:笔记路径或通配(* ? [abc]),相对 path
  "技能库/本机模型能力矩阵.md",
  "技能库/音视频*.md",
]
exclude = []
restricted = ["技能库/成人向*", "技能库/NSFW*"]   # 这些笔记按 rating 处理(默认 restricted)
rating = "restricted"
```

**只读 include 清单里的笔记**:清单为空就什么也不读(同步会提示),vault 里其余的笔记(工作、个人资料……)不会进入系统。
`.obsidian`、`.trash` 等隐藏目录不读;单个文件超过 2 MiB 跳过。

## 受限笔记

`restricted` 清单里的笔记带 `rating`(默认 `restricted`),和受限图片同一套门:

* 没解锁、或账号批准的年龄不够时,列表里看不到,搜索不出来,直接打开返回 403(`content_locked` / `age_restricted`);列表只告诉你"有 N 页被锁"。
* 解锁(顶栏)后可读,每次打开写一条审计记录。
* 受限页面里的图片不会被复制出来。

## Obsidian 语法

同步时转成普通 Markdown:`[[页面|别名]]`、`[[页面#标题]]`、`![[页面]]` 变成站内链接(找不到的目标留下纯文字);`![[图.png]]` 复制到
`$STORY_AGENT_HOME/wiki/assets/` 后以图片显示;`> [!tip] 标题` 变成带 **TIP** 的引用块;`%%注释%%` 去掉;`==高亮==` 变粗体;`^块标记` 去掉;
代码块和行内代码不动。frontmatter 的 `tags` 成为标签,`title` 作为标题(否则取第一个 `# 标题`,再否则取文件名)。
`docs` 里的相对 `.md` 链接也会变成站内链接。

## 用法

```bash
.venv/bin/python -m storyagent wiki sync                 # 读取来源,新增/更新/移除页面(幂等)
.venv/bin/python -m storyagent wiki list [-q 关键词] [--source obsidian] [--tag AI]
.venv/bin/python -m storyagent wiki show obsidian/技能库/本机模型能力矩阵
```

网页:**知识库** → 右上角"同步"按钮、搜索框(标题、标签、正文,中文可直接搜)、来源和标签过滤、本页目录、"哪些页面链接到这里"。
项目的**模型管线**面板里每个模型旁有"笔记"链接,直接搜这个模型的资料。

## 知识图谱

网页 **知识库** 顶部的 **列表 / 图谱** 切换。图谱把页面画成点、页面之间的链接画成线(`wiki sync` 已把 `[[...]]` 和 docs 里的相对 `.md` 链接解析好),比列表更容易看出"这页和谁有关"。

* 点的大小 = 连接数(被链接数 + 链出数);颜色按 **来源**(docs / obsidian……)或 **标签**(最常用的 7 个标签各一种颜色,其余灰色)。
* 鼠标悬停:高亮这个点和它的直接邻居,其余变淡,并显示标题、来源、标签、摘要和连接数。
* 点击页面点:打开该页(页面显示在图旁边,图里用粗圈标出当前页)。拖动点可移动位置,拖背景平移,滚轮或 +/- 缩放,"适应窗口"回到全貌。点标签点 = 按该标签过滤;点模型点 = 只看提到该模型的笔记。
* **范围**:全部,或"当前页周围(1 跳 / 2 跳)"(链接不分方向)。页面详情里还有一张"这一页周围"的小图(含它提到的模型),"在图谱里打开"可放大。
* **筛选**:搜索词、来源、标签,和列表共用同一组控件。搜索时命中的页面正常显示,只和命中页有链接的页面(用来看上下文)变淡。
* **同时画出**:`标签`(每个被 2 页以上使用的标签一个方块点,页面连到它)、`有 2 个以上相同标签的页面`(两页没有直接链接但至少共有 2 个标签时画虚线,共有标签越多越粗;一个标签上超过 40 页不参与,太泛)、`模型`(见下)。
* 没有任何连线的页面不画在图里,而是单独列在图下面("没有任何链接的页面")。
* **性能上限**:一次最多画 300 页(可点"最多显示 1000 页"提到 1000);超出时只保留连接最多的页面并提示"只画了连接最多的 N 页(共 M 页)"。几百个点是流畅的;过滤、搜索或聚焦到某页后点数就少了。

### 模型节点

`models.toml` 里的模型按 **模型族**(`family`,没写就是模型名本身)合成一个菱形点,和提到它的页面相连(实线,强调色)。匹配规则:

1. 用模型族名和该族每个模型名(如 `ltx-2.5`、`ltx-2.5-av`)去找;少于 4 个字符的名字不找。
2. 在页面标题、标签、正文里找(链接的目标地址不算正文);不分大小写,空格和下划线当作连字符,所以"LTX 2.5"能找到 `ltx-2.5`。
3. 名字前后不能紧挨着字母或数字(`ltx-2.55` 不算 `ltx-2.5`),但 `-`、`.`、空格、标点都可以(`ltx-2.5-av` 里的 `ltx-2.5` 也算提到)。
4. 只画至少有一个可见页面提到的模型;连线的权重 = 提到次数。

点模型点就是"这个模型有哪些笔记":图只显示提到它的页面,图上方的卡片把这些页面逐条列出(标题、来源、开头几行),点一条就在旁边读全文;点标签点同样列出带这个标签的页面。窄屏上阅读器在图的下方,选中页面时会自动滚到可见位置。项目的 **模型管线** 面板里每个模型旁有"图谱"链接,直接跳到这个视图。模型本身要在某个项目的方案里选用,所以模型点上的链接指向项目列表,而不是某个固定的管线页。

## 知识问答

知识库页顶部的"问问知识库"框(列表和图谱两种视图都有):用自然语言提问,系统在可见的页面里找最相关的段落,交给本地语言模型 **只依据这些段落** 作答,回答里每个结论后面标 `[n]`,点 `n` 打开出处页面;下面列出出处(页面、章节、摘录),用到的页面在图谱里高亮。

* **检索**:不建索引,直接读页面(页面少而短)。中文切成相邻两字,其他文字按词;出现在越少页面里的词权重越大,标题和标签命中加分;页面按标题切成章节,答案引用的是具体章节。疑问词("什么""怎么")不参与检索。
* **只依据笔记**:回答用的角色是 `knowledge`(`llm.toml`,默认 `gemma4:31b`,可在「语言模型」页改)。提示词要求没找到就说没有、不要凭记忆补;模型答了却没标出处时,界面提示"没有出处,请核实"。没有任何页面沾边时不调用模型,直接说没找到。
* **受限笔记**:只检索当前看得见的页面(没解锁就读不到);用到受限页时按打开它记审计,回答按该分级作答:走 `[llm.ratings.<分级>]` 指定的本地模型,后端不在本机则拒绝,模型调用日志里只留摘要。
* **只读**:不改任何内容,不保存问答。登录用户(含只读账号)都可以问。
* API:`POST /api/wiki/ask` `{question, language, source?, limit?}` → `{found, grounded, answer, reason, sources[{n, slug, title, source, rating, heading, snippet, cited}], backend, model, seconds}`;`reason = "no_match"` 表示没有页面沾边。

### 受限笔记与图谱

图谱遵守和列表同一套规则:受限笔记在未解锁(或年龄不够)时 **不是节点,不是任何一条边的另一端,也不计入任何数字**(连接数、标签点和模型点上的页数都只数看得见的页面;只有 `hidden` 一个总数,和列表里的"有 N 页被锁"一样)。以这样一页为 `focus` 打开返回 403。解锁后它们和普通页面一样出现。注意:可见页面自己正文里写的链接文字(如 `[[某受限页]]`)是那一页自己的内容,不属于图谱数据,图谱不会替它隐藏。

URL 参数(可直接分享):`/wiki/<slug>?view=graph&scope=1|2&model=<模型族或模型名>&color=tag&layers=tags,shared,models&q=&source=&tag=`。

API:`GET /api/wiki/pages?q=&source=&tag=`、`GET /api/wiki/graph`(见下)、`GET /api/wiki/pages/{slug}`、`POST /api/wiki/sync`(需要写权限)、`GET /api/wiki/assets/{name}`。

## i18n

界面文字都是 `web.wiki.*` / `cli.wiki.*` 键;页面内容本身是你的笔记原文,不翻译。

## 图谱接口

`GET /api/wiki/graph`,参数(都可省):

| 参数 | 说明 |
|---|---|
| `source`、`tag` | 只要这个来源 / 带这个标签的页面 |
| `q` | 搜索词(同列表的搜索):命中的页面 + 和它们有链接的页面(后者 `match=false`,只作上下文) |
| `focus` | 页面 slug:该页和它 `depth` 跳以内的页面(链接不分方向);或 `model:<模型族或模型名>`:提到该模型的页面(`depth=2` 再加它们的邻居)。`source`/`tag` 再在这个范围里过滤;此时 `q` 只标记 `match`,不缩小范围。页面不存在 / 模型未知 404,受限页面未解锁 403 |
| `depth` | `1` 或 `2`(默认 1,只对 `focus` 有用) |
| `include_tags` | 加标签节点(被 ≥2 个页面使用的标签)和页面→标签的边(`kind=tag`) |
| `shared_tags` | 加页面之间的弱边(`kind=shared_tag`,`weight` = 共有标签数,至少 2 个,且两页没有直接链接) |
| `include_models` | 加模型节点和 `kind=mention` 的边(`weight` = 提到次数);`focus=model:...` 时自动打开 |
| `limit` | 最多画多少页,默认 300,最大 1000;超出则保留连接最多的页面并 `truncated=true` |

返回 `nodes`(`kind` = `page` / `tag` / `model`;页面带 `title`→`label`、`source`、`tags`、`rating`、`summary`、`links_in`、`links_out`、`isolated`、`match`;标签/模型节点的 `pages` 是视图里有多少页;模型节点带 `refs`、`model_kind`)、`edges`(`source`、`target`、`kind` = `link` / `tag` / `shared_tag` / `mention`、`weight`)、`total`、`hidden`、`matched`(过滤后、截断前的页数)、`truncated`、`limit`、`focus`、`depth`,以及 `sources` / `tags` 的计数(给过滤控件用)。节点 id:页面是 slug,标签 `tag:<名>`,模型 `model:<族>`。`links_in` / `links_out` 数的是整个知识库里看得见的页面,不随过滤变化。
